# Cielo fotografico

`sky.hdr`: "Overcast Soil (Pure Sky)" di Poly Haven, https://polyhaven.com/a/overcast_soil_puresky
Licenza CC0 (pubblico dominio): nessun obbligo di attribuzione. Risoluzione 2k.

Il gioco la carica all'avvio (DeferredRenderer::LoadSky): cielo visibile, riflessi prefiltrati e luce d'ambiente.
Per cambiare cielo basta sostituire il file con un altro HDRI equirettangolare (.hdr). Opzioni > Grafica regola
intensita', tinta e rotazione.
